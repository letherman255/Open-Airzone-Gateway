# Contributing

Thanks! The most useful contributions are recordings and diagnostics from installations that are not
documented yet, confirmed registers, and hardware. Start with [docs/contributing.md](docs/contributing.md)
(catalogue entries, how to confirm a setting safely), [docs/development.md](docs/development.md) (build and
tests) and [hardware/README.md](hardware/README.md). Please use the issue templates.

Support is best effort, and the author can only test on one installation: see
[Support](README.md#support). Reports and pull requests from other installations are what moves the project.

Code is MIT, hardware is CERN-OHL-P-2.0. Everything is written in English.
