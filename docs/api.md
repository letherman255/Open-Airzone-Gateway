# Local API

Base URL `http://<gateway>/api/v1/`, JSON in and out. Full route list: [openapi.yaml](openapi.yaml)
(generated by `tools/gen_openapi.py`). Reads are public; changes need `Authorization: Bearer <token>`.

```sh
# session token (or create an API token on the Gateway page)
curl -s -X POST http://GATEWAY/api/v1/login -d '{"password":"…"}'
# zone 2 of central 1
curl -s http://GATEWAY/api/v1/systems/1/zones/2
# setpoint 21.5 °C (master mode)
curl -s -X POST -H "Authorization: Bearer TOKEN" http://GATEWAY/api/v1/params/zone.setpoint -d '{"system":1,"zone":2,"value":21.5}'
# answers {"queued":7}; then
curl -s -H "Authorization: Bearer TOKEN" http://GATEWAY/api/v1/writes/7
```

- Enumerations accept the label (`"cool"`) or the code. Dangerous settings answer 403 with the warning and
  the word to send back as `"confirm"`.
- Writes answer 202 and are applied on the next bus cycle; the result (`applied`, `rejected`, `no_answer`,
  `unverified`) comes from a re-read of the register.
- In listen mode every bus write answers 409.
- Developer mode (`POST /dev {"on":true}`) enables `/registry`, `/raw/{addr}/{reg}` and `/raw/write`.
- `GET /ws` (WebSocket) sends `{"topic":"values","states":[…]}` every 2 s. **Send one text frame (any
  content) right after opening**: the ESP-IDF server does not report the handshake, the first frame
  registers the client.
- TCP port 7000 streams every bus frame as text (`<t_us> <len> <hex>` lines), for recordings.

## Installing an update

`GET /info` shows `latest_version`, `latest_url` and `update_state` (empty when idle, otherwise
`downloading 37%`, `installing`, `restarting` or `failed: <reason>`). `POST /api/v1/update/install`
(admin token) installs the release found by the update check: 202 `{"installing": "<version>"}`, 409
when there is no update or one is already running, 400 when the image URL is not HTTPS. Never automatic
and not available over MQTT.

## Command line

`tools/gwctl.py` (Python standard library) wraps the API: `info`, `login`, `get`, `set` (waits for the
result), `raw`, `watch` (WebSocket messages), `backup`, `restore`, `update [--install]` (shows the available release; `--install` downloads and flashes it, then waits), `ota`. Token from `--token`,
`--token-file` or `GWCTL_TOKEN`; exit status 1 on any API error.

```sh
python -I tools/gwctl.py --host 192.168.1.50 --token-file token.txt set zone.setpoint 21.5 --zone 2
```
